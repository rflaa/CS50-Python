# 🐍 CS50 Python: Introduction to Programming with Python

This repository contains my solutions to the problem sets from **[CS50's Introduction to Programming with Python](https://cs50.harvard.edu/python/)**, offered by Harvard and taught by David J. Malan.

The course covers the fundamentals of Python programming, with a focus on problem solving and good coding practices.

## Contents

Each folder corresponds to a week of the course and contains the programs for that week's problem set:

| Week | Topic |
|------|-------|
| 0 | Functions, Variables |
| 1 | Conditionals |
| 2 | Loops |
| 3 | Exceptions |
| 4 | Libraries |
| 5 | Unit Tests |
| 6 | File I/O |
| 7 | Regular Expressions |
| 8 | Object-Oriented Programming |
| 9 | Et Cetera |
